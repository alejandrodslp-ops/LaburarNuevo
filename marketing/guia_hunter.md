# Guía práctica — Hunter (y alternativas) para conseguir emails

## Cómo contratar Hunter
1. Entrá a **hunter.io** → "Sign up" (con Google o email). Cuenta **gratis**.
2. Confirmá tu email.
3. El plan gratis da ~25–50 búsquedas/mes + verificaciones → **suficiente para probar**.
4. Si funciona con tus empresas → subís a un plan pago (tarjeta, mensual, se cancela cuando quieras).
   Precio: arranca alrededor de **US$34/mes** — **verificá el precio actual** en hunter.io/pricing (cambia seguido).

## Cómo se usa
- **Domain Search:** pegás el dominio (ej. `riberman.com.br`) → lista los emails + el patrón (contato@, rh@…).
- **Email Finder:** nombre de persona + dominio → el email más probable.
- **Bulk** (pago): subís un CSV de **dominios** → devuelve emails de todos.
- **Extensión de Chrome de Hunter:** navegás el sitio y te muestra los emails de esa página.
- **Verifier:** chequea si un email existe (evita rebotes).

## ⚠️ El detalle clave para TU caso
- Hunter trabaja con **dominios**. Tu lista son **nombres**. Primero necesitás el dominio de cada empresa
  (el paso difícil que ya vimos). Para listas de **nombres**, **Apollo.io** suele venir mejor (busca por
  nombre de empresa + rubro + ciudad y exporta contactos).
- Para **PyMEs chicas de Brasil**, la cobertura de estas herramientas es **floja** (indexan mejor empresas
  grandes/tech/internacionales). Por eso: **probá GRATIS con 5–10 de tus empresas ANTES de pagar** y
  confirmá que realmente las encuentra. No pagues a ciegas.
- **LGPD (Brasil):** para envío masivo el riesgo sigue siendo la lista scrapeada. Mantené el opt-out
  ("responda sair") y andá de a poco.

2. Medí si responden.
3. Si el mensaje funciona → recién ahí probá Hunter/Apollo **gratis** con unas pocas.
4. Si la cobertura sirve → pagás un mes y escalás; yo te limpio y personalizo el resultado.
